1. Why Zustand here: Recovery state updates frequently (checklist step toggles, live complaint draft keystrokes) and is shared across distant components (Navbar badge, checklist progress bar, complaint draft preview); Zustand provides granular selectors to re-render only subscribed components without context cascades, combined with `persist` middleware for seamless localStorage durability.
2. How progress persistence works: The store persists completed step IDs (`completedSteps: [...]`) and form values (`draft: {...}`) to localStorage via Zustand's `persist` middleware, so action ticks and draft text remain intact across page refreshes and navigation without needing a background timer loop.
3. How nested routes and Outlet are used: In `App.jsx`, `/recover` is configured as a layout route rendering `RecoverLayout` (shared header and 2-step stepper); child routes `index` (Step 1 `RecoverChecklist`) and `complaint` (Step 2 `ComplaintDraft`) are injected dynamically via React Router's `<Outlet />`.
4. How validation runs (blur vs submit): On blur, `handleBlur` marks the field as touched and computes that field's error; on change after being touched, `handleChange` re-validates live for instant feedback; on submit, `handleSubmit` marks all fields touched, runs full form validation, and programmatically focuses the first invalid DOM element for accessibility.
5. How the Blob download works: `handleDownloadTxt` packages plain text into `new Blob([complaintPlainText], { type: 'text/plain;charset=utf-8' })`, generates an object URL via `URL.createObjectURL(blob)`, triggers native browser download via an ephemeral anchor tag with the `download` attribute, and immediately releases memory with `URL.revokeObjectURL(url)`.
6. What would change with a real backend: A real backend would store recovery incidents via authenticated REST/GraphQL endpoints (e.g. `POST /api/recovery`) with server-stamped audit logs, encrypt victim PII at rest, and provide automated incident forwarding directly to state cyber cells or the national 1930 / cybercrime.gov.in API.
